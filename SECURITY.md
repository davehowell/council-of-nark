# Security policy

This is a public prompt, presentation, and experiment repository. Do not submit real credentials, private customer data, private incident details, internal hostnames, or proprietary source artifacts in an issue or pull request.

If you find a secret in the repository or its Git history, report it privately through GitHub's security-advisory feature. Include the path and commit. Do not paste the secret into a public issue.

The synthetic experiment packets contain invented organisations and placeholder values. They are not production artifacts.
